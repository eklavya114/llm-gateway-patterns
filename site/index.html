Why this exists

Every one of these has happened to a real team.

Not hypotheticals — the failure modes that show up the first time an LLM feature touches real users, real data, and a real usage bill.

Data leak

"Support copilot repeated a customer's SSN back in the chat transcript."

Fixed by the streaming redaction gateway — catches PII in flight, even split across chunks.
Privilege escalation

"An intern's API key just called the admin-only refund tool."

Fixed by the MCP gateway — blocks non-admin tokens from admin_* tools before downstream is touched.
Outage

"Our model provider had a 20-minute blip and our product went down with it."

Fixed by the failover router — 3-second budget on the primary, automatic handoff to a backup provider.
Cost blowout

"One customer's misbehaving script burned a month of token budget in an hour."

Fixed by the sliding-window rate limiter — hard per-tenant caps, enforced on-disk, survives restarts.
How a request actually moves

The gateway sits in the path, not on top of it.

Requests pass through validation, auth, redaction, and rate-limit checks before they ever reach a model provider — and every failure mode has a defined, sanitized response instead of an unhandled crash.

01
Client call
Tool call or completion request arrives with a bearer token.
→
02
Auth & schema check
Role verified, input validated with Zod. Malformed input never reaches handler logic.
→
03
Rate-limit gate
Sliding-window check against on-disk SQLite. Over budget → rejected before any provider call.
→
04
Provider call + failover
3000ms budget on primary. 429, timeout, or error → automatic handoff to secondary.
→
05
Redact & stream out
Response streamed back through the overlap buffer, PII replaced in flight.

The four modules

Standalone. No shared dependency tree.

Each one runs on its own, ships its own tests, and can be adopted independently.

01 MCP Server
Schema-validated tool calls over stdio. Invalid input returns a real JSON-RPC -32602, not a swallowed error.
→
02 Gateway Auth
JWT role claims gate every admin_* tool call before it reaches the downstream server.
→
03 PII Redaction
Streams and redacts emails, SSNs, and card numbers without buffering the response — even across chunk splits.
→
04 Rate Limit & Failover
Per-tenant token quotas backed by SQLite, plus automatic primary→secondary handoff on failure.
→
