# site/

The product showcase page — a single static HTML file with a live,
in-browser port of the PII redaction engine from
[task-3-llm-pii-redaction-gateway](../task-3-llm-pii-redaction-gateway/).

No build step, no dependencies. Open `index.html` directly in a browser, or
serve the folder with any static file server:

```
npx serve site
```

Deployed on Vercel from this folder as the project root.
